# 🎥 Project Demonstration

## Overview

This video demonstrates the end-to-end workflow of the **APT29 Adversary Emulation and Threat Detection** project.

The demonstration covers adversary emulation, telemetry collection, Elastic Security detection.

> [!IMPORTANT]
> The demonstration was recorded in an isolated and authorized SOC laboratory for educational purposes.

## Demonstration Contents

The video presents:

1. The SOC laboratory environment
2. Elastic Agent and Fleet connectivity
3. The MITRE CALDERA APT29 profile
4. Execution of selected APT29 techniques
5. Collection of Windows and Sysmon telemetry
6. Elastic Security alert generation
8. MITRE ATT&CK technique mapping
10. Detection and validation results
